# Смешарики — мобильный Fullscreen HTML5

В Adfox: шаблон Fullscreen HTML5 [context], ширина 100%, высота 100%. Панель управления и закрытие настраиваются в Adfox. Подложка обертки должна быть прозрачной, чтобы белая подложка креатива с непрозрачностью 40% показывала сайт. URL перехода задается только в Adfox.

Анимация однократная, 3,46 секунды после загрузки изображений, затем статичная афиша. При prefers-reduced-motion сразу афиша. Весь текст в banner/index.html в блоке copy. Кнопка повторения находится только на странице согласования и в ZIP не входит.

Графика: предоставленный фон с четырьмя персонажами; чистый прозрачный спрайт создан встроенной генерацией по референсу. Запрос: шесть поз Кроша в сетке 3×2, нейтральная, приземление, взгляд влево, вправо, улыбка и прыжок к зрителю; прозрачный фон без артефактов.
